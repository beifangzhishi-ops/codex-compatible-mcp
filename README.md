# CCM — Codex-Compatible MCP

CCM is a Codex-inspired harness for GPT over MCP.

Initial design goals:
- Codex-style execution: exec_command, write_stdin, apply_patch, view_image.
- Remote environments for Windows/Linux workers.
- Plan Mode and persistent Goal runtime.
- Code Mode with a nested ToolRegistry.
- MCP resource aggregation.

The project is intentionally developed locally first. No Git remote is configured yet.
